# Answer Before Action

## Trigger
Any owner message that contains a question.

## Action
1. **Stop** execution, implementation, and planning.
2. **Answer** the question directly, concisely, and completely.
3. **Only then** ask for permission to proceed with the original plan or a new plan.

## Forbidden
- ❌ Treating the answer as implied by your actions.
- ❌ Burying the answer inside a large block of code, unless code was asked for.

Related: the end-with-answer rule in `AGENTS.md` (every reply ends with the answer or the blocking question).
